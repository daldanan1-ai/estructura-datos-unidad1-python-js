# Estructura de Datos - Unidad 1 (Actividad Protocolo Individual)

Universidad de Cartagena - Ingeniería de Software.
Ejercicio asignado: **1. Analizador de Calificaciones**, desarrollado en **Python** y **JavaScript**.

## Estructura

```text
estructura-datos-unidad1/
├── README.md
├── .gitignore
├── python/
│   ├── ejemplos_arreglos.py
│   ├── ejemplos_matrices.py
│   └── analizador_calificaciones.py
└── javascript/
    ├── ejemplosArreglos.js
    ├── ejemplosMatrices.js
    └── analizadorCalificaciones.js
```

## Requisitos

- Python 3.8 o superior (probado con 3.9.6)
- Node.js 18 o superior (probado con 24.21.0)

No se usan librerías externas.

## Ejecución

```bash
# Python (en Windows también puede ser: py archivo.py)
python python/ejemplos_arreglos.py
python python/ejemplos_matrices.py
python python/analizador_calificaciones.py

# JavaScript (Node.js)
node javascript/ejemplosArreglos.js
node javascript/ejemplosMatrices.js
node javascript/analizadorCalificaciones.js
```

## Qué hace cada programa

| Programa | Descripción |
|---|---|
| `ejemplos_arreglos` / `ejemplosArreglos` | Arreglo de 10 enteros: creación, recorridos, modificación y búsqueda lineal |
| `ejemplos_matrices` / `ejemplosMatrices` | Matriz 3x3: tabla, recorrido por columnas, suma e intercambio de filas |
| `analizador_calificaciones` / `analizadorCalificaciones` | Lee N calificaciones (0-100) y calcula promedio, mediana, moda, % de aprobados/reprobados e histograma en texto |
